# TAIAO v0.1

A small, phone-friendly prototype for TAIAO — a Māori-first digital companion concept.

## What this prototype does

- Shows a TAIAO companion on screen
- Tracks hunger, happiness and energy
- Lets you feed, play, rest and explore
- Lets time pass naturally
- Saves the companion in your browser
- Includes a simple te reo Māori vocabulary layer
- Works as a plain HTML/CSS/JavaScript project — no build tools required

## Run it

The easiest option is to open `index.html` in a browser.

For local development, use any simple static server. For example, with Python installed:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## GitHub

1. Create a new GitHub repository called `taiao`.
2. Upload all files from this folder.
3. To publish it as a website, enable GitHub Pages for the repository.
4. The app can then be opened on a phone from the published page.

## Important cultural note

This is a product prototype, not a finished representation of Māori culture or mātauranga Māori.
Before commercial release, TAIAO should be developed with appropriate Māori cultural, language and creative governance.
